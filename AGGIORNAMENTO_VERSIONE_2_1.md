# SentencePiece Lab 2.1 – grafica e leggibilità

**Non modifica il motore dei tokenizer, i modelli o le API.**

## Cosa cambia
- Tipografia uniforme (Arial / Segoe UI, con fallback Unicode), titoli più evidenti.
- Spiegazioni, etichette, pulsanti e metriche più leggibili.
- Contrasto aumentato e colori più sobri, selezione delle schede più evidente.
- Spaziature ottimizzate per i monitor universitari (schermi da 1280×720 in su).
- Mantiene le 4 schede; nei testi lunghi scorre solo l’area token.

## Come aggiornare GitHub / Render
Sostituisci nel repository `sentencepiece-lab` i file `static/styles.css` e `static/index.html` con quelli del pacchetto di aggiornamento. Premi **Commit changes**. Render effettua il deploy automatico; in caso contrario usa **Manual Deploy → Deploy latest commit** sul servizio SentencePiece Lab (NON su Calcolo Cilindri).

Aggiorna il browser con **Ctrl+F5**.
